# T1 Arc film production workspace

This optional Remotion workspace produces the T1 Arc product film. It is not
part of the Android app or an installation step. App users should follow the
[main download guide](../../../README.md) and install a published APK.

The selected current demo, poster and subtitles live in
[docs/media](../../../docs/media/README.md). That is the viewing and sharing entry
point, including separate audio rights and the required elevenlabs.io title credit.

## Current edition

The current film runs for 90 seconds at 60 fps, with separate landscape and
portrait layouts. It combines George's British AI narration, the owner's Suno
track *Signal Drift*, the privacy ending and the refreshed food scene:

- Today, Health, Tarv1s question/answer and Timeline: 0–66 seconds.
- Current food UI and an unsaved example portion: 66–80 seconds.
- Open-source/local-history message and direct-OpenAI qualifier: 80–90 seconds.

The food refresh uses genuine app capture from a synthetic emulator profile.
Other scenes include the creator's own records with permission. Editorial cuts
and reading holds are not response-time benchmarks; the food draft is not
presented as a saved meal. No app frames are generated by AI.

The local production delivery is `out/food-refresh/`: 4K, sharing and sub-10 MB
web copies, posters, captions and verification reports. See the
[food-refresh delivery notes](narration/FOOD-REFRESH-DELIVERY.md).
Only deliberately selected copies in `docs/media/` are repository viewing assets;
generated production directories remain excluded.

## Maintainer setup

Use this directory's pinned lockfile and dependencies, not the Android app's
dependency installation. Rendering also needs a compatible Chromium runtime
and FFmpeg/FFprobe with H.264 support.

```sh
cd tools/promo/v4
npm ci
npm run lint
```

A fresh clone does not contain the production inputs. `public/captures/`,
`.render/`, `out/`, `node_modules/` and environment files are excluded.
Supply your own appropriately authorised captures, audio and any prior-edition
masters needed by the chosen pipeline. The selected demo is not an unrestricted
source-media pack for forks.

- `src/`: scene typography, original 3D phone, lighting and camera movement.
- `src/assets.ts`: expected excluded capture filenames.
- `src/Root.tsx`: compositions, including separate fourteen-second food-refresh shots.
- `narration/`: scripts and edition-specific production records.
- `scripts/prepare-food-refresh.mjs`, `render-food-refresh.mjs` and
  `export-food-refresh.mjs`: the prepared-input refresh pipeline.

Follow the [delivery reproduction steps](narration/FOOD-REFRESH-DELIVERY.md#reproduce-from-the-review-checkout).
Simply rendering the historical base `T1Arc-Film-*` composition does not reproduce
the final privacy-and-food-refresh edition. The export pipeline preserves the
existing audio and earlier/later scenes and verifies frames, splice integrity,
captions and file size. Also inspect the pictures: numeric checks cannot establish
visual accuracy or media permissions.

Keep credentials outside the repository and browser bundle. Viewing the selected
demo or rendering from prepared local assets requires no narration-generation
API call. New third-party generation is a separate, deliberate production action,
not an app setup prerequisite.
