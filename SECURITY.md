# Security policy

T1 Arc handles health records and account credentials, so privacy and security reports are taken seriously.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or privacy failure. Use [GitHub private vulnerability reporting](https://github.com/gregorgregor25/t1-arc/security/advisories/new) instead.

Include:

- the affected version or commit;
- the device and Android version;
- clear reproduction steps;
- the impact you believe is possible;
- a suggested fix, if you have one.

Do not include real API keys, account passwords, session tokens or another person's health data. Redact screenshots and logs before attaching them.

You should receive an acknowledgement when the report is reviewed. Timelines for a fix will depend on severity, reproducibility and the amount of change required. Please allow time for a safe release before discussing the report publicly.

## Supported versions

T1 Arc is in active development. Security fixes are applied to the current development version. Older builds may not receive separate patches.
