No public portrait download is currently offered. The website hosts the 90-second landscape edit with captions.

This is an edited demonstration, not a real-time performance benchmark. Some
scenes show the creator's own records with permission. The food scene uses a
temporary example and shows a draft, not a successfully saved meal. Responses
describe the records shown; they are not health outcomes caused by using T1 Arc.
