# Retired Orbit resources

Orbit is not part of the current collection or any release build.
These old resources and their recorded application ID remain as a compatibility
reference for previously installed APKs. The companion keeps its original Orbit
graph provider so an installed face is not broken by an update.

The current faces are Meridian, Chronograph, Atelier, Pace and Summit.
See [the collection design notes](../../docs/design/WATCH_FACE_COLLECTION.md).
